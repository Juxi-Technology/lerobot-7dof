# Windows 컴퓨터

`장치 관리자`를 열고 `Follower 암`을 먼저 꽂은 다음 `Leader 암`을 꽂고, 해당 COM 포트 번호를 확인합니다

![이 이미지는 Windows 장치 관리자의 포트(COM 및 LPT) 아래에 있는 USB-Enhanced-SERIAL CH343 (COM6) 및 USB-Enhanced-SERIAL CH343 (COM7) 장치를 보여 줍니다. COM6는 Follower로 빨간 박스로, COM7은 Leader로 초록 박스로 표시되어 있습니다. 이는 Follower를 COM6로, Leader를 COM7로 기록하는 단계와 호응하며, 장치 관리자에서 해당 포트를 식별하는 것을 시각적으로 보여 줍니다.](../../en/images/d10-01.png)
