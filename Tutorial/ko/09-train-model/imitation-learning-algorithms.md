# LeRobot가 지원하는 모방 학습 알고리즘

https://github.com/huggingface/lerobot/tree/main/src/lerobot/policies

![이 이미지는 LeRobot가 지원하는 모방 학습 알고리즘의 체계를 보여줍니다. 맨 위에 "Robot Learning"이 있고, 크게 두 갈래인 "Behavioral Cloning (BC)"과 "Reinforcement Learning (RL)"로 나뉩니다. BC 아래에는 "Single-task policies"가 ACT, Diffusion Policy, VQ-BET 등을 포함하고, "Generalist policies"가 π0와 SmolVLA를 포함합니다. RL 아래에는 HIL-SERL과 TD-MPC가 있습니다. 이 이미지는 LeRobot가 지원하는 모방 학습 알고리즘을 소개하는 절과 관련되어, 그 분류 체계와 구체적인 알고리즘을 시각적으로 보여줍니다.](../../en/images/d32-01.png)
