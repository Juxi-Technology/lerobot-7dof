# Windows コンピューター

`デバイスマネージャー` を開き、`Follower アーム` を先に、次に `Leader アーム` を接続して、対応する COM ポート番号を確認します

![この画像は、Windows のデバイスマネージャーの「ポート (COM と LPT)」に表示された USB-Enhanced-SERIAL CH343 (COM6) と USB-Enhanced-SERIAL CH343 (COM7) のデバイスを示しています。COM6 は赤枠で Follower、COM7 は緑枠で Leader として印が付けられています。これは Follower を COM6、Leader を COM7 として記録する手順と対応し、デバイスマネージャーで該当するポートを識別する様子を視覚的に示しています。](../../en/images/d10-01.png)

## 自分のポート番号を記録する

Follower アーム：

COM6

Leader アーム：

COM7
