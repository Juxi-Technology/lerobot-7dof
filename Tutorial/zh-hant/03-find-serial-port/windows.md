# Windows電腦

開啟`裝置管理員`，先插上`從動臂`，再插上`主動臂`，檢視對應的COM埠編號

![圖片展示了Windows電腦裝置管理員中連接埠（COM和LPT）下的USB - Enhanced - SERIAL CH343（COM6）和USB - Enhanced - SERIAL CH343（COM7）裝置。其中，COM6被紅色框標註為從動臂，COM7被綠色框標註為主動臂。這與文件中記錄從動臂為COM6、主動臂為COM7的操作步驟相呼應，直觀呈現了裝置管理員中對應連接埠的標識情況。](../../en/images/d10-01.png)
