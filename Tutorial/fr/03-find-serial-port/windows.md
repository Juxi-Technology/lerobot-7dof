# Ordinateur Windows

Ouvrez le `Gestionnaire de périphériques`, branchez d'abord le `bras Follower` puis le `bras Leader`, et vérifiez les numéros de port COM correspondants

![L'image montre les périphériques USB-Enhanced-SERIAL CH343 (COM6) et USB-Enhanced-SERIAL CH343 (COM7) sous Ports (COM & LPT) dans le Gestionnaire de périphériques Windows. COM6 est marqué d'un cadre rouge comme le Follower, et COM7 d'un cadre vert comme le Leader. Cela fait écho aux étapes consistant à noter le Follower comme COM6 et le Leader comme COM7, et présente visuellement l'identification des ports correspondants dans le Gestionnaire de périphériques.](../../en/images/d10-01.png)

## Noter mes numéros de port

Bras Follower :

COM6

Bras Leader :

COM7
