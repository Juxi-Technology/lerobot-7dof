# Windows电脑

打开`设备管理器`，先插上`从动臂`，再插上`主动臂`，查看对应的COM口编号

![图片展示了Windows电脑设备管理器中端口（COM和LPT）下的USB - Enhanced - SERIAL CH343（COM6）和USB - Enhanced - SERIAL CH343（COM7）设备。其中，COM6被红色框标注为从动臂，COM7被绿色框标注为主动臂。这与文档中记录从动臂为COM6、主动臂为COM7的操作步骤相呼应，直观呈现了设备管理器中对应端口的标识情况。](../../en/images/d10-01.png)
